# Security Policy

## Supported versions

The project is pre-release. Security fixes target the latest commit on `main`.

## Reporting a vulnerability

Open a GitHub security advisory or contact the maintainer privately. Do not publish real Jira ticket contents, secrets, or PII in public issues.

## Data handling

TicketScrub should use synthetic fixtures in this repository. The intended product direction is local-only detection by default. Any future hosted or telemetry feature must be opt-in and documented before implementation.
