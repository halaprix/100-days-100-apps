# Contributing

StatePin is early-stage. Keep contributions small, testable, and public-safe.

## Development rules

- Use conventional commit messages.
- Use Beads (`bd`) for task tracking.
- Keep examples synthetic.
- Prefer boring implementations over clever architecture.

## Before opening a PR

- Run `python3 scripts/verify_scaffold.py` while this repo is scaffold-only.
- If implementation exists, add and run the relevant tests/build command.
- Do not include secrets, private URLs, real webhook endpoints, or personal infrastructure details.
