# Security Policy

## Supported versions

StatePin is pre-release. Only the latest alpha scaffold is maintained.

## Reporting a vulnerability

Open a GitHub security advisory or a private maintainer report if a public remote exists. Until then, report issues through the parent 100-days index context.

## Public-safety boundary

Do not submit real webhook URLs, signing secrets, private hostnames, private IPs, credentials, raw logs, or screenshots containing personal data. Use synthetic `.test` examples and fake timestamps.
