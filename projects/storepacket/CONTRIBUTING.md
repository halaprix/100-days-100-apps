# Contributing

Thanks for considering a contribution.

## Workflow

1. Pick or create a Beads issue with `bd`.
2. Make one focused change.
3. Add or update tests/fixtures when behavior changes.
4. Commit with a Conventional Commit message.
5. Open a PR with the validation output.

## Development principles

- Local-first by default.
- No App Store Connect credentials in the MVP.
- Deterministic outputs that can be tested from fixtures.
- Clear boundaries around Apple trademarked terms: use them descriptively, not as product branding.
