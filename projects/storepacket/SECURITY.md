# Security Policy

## Supported versions

StorePacket is currently pre-release. Security fixes will target the latest alpha branch.

## Reporting a vulnerability

Open a private security advisory on GitHub if available, or contact the maintainer through the repository owner profile.

## Sensitive data policy

Do not include real App Store Connect credentials, API keys, customer data, private screenshots, demo account passwords, or unpublished app metadata in issues, pull requests, fixtures, or generated packets.

The MVP should not request or store App Store Connect credentials.
