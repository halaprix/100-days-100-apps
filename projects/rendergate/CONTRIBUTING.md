# Contributing

RenderGate is currently an incubator scaffold. Contributions should keep the project local-first, deterministic, and public-safe.

## Rules

- Use Conventional Commits.
- Use Beads for task tracking.
- Add tests for rule changes.
- Do not add real infrastructure data, credentials, or private network examples.
- Prefer small, reviewable changes.

## Local validation

For scaffold-only changes, verify required files exist and public-safety checks pass. Once code lands, add the project test command here.
