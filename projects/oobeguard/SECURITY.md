# Security Policy

## Supported versions

OOBEGuard is pre-release. Security fixes apply to the latest public pre-release only.

## Reporting a vulnerability

Open a GitHub security advisory or a private report if the issue involves sensitive data. Do not include private fleet inventory, activation data, hostnames, serial numbers, IP addresses, or production logs in public issues.

## Security boundaries

OOBEGuard should not collect private device data or modify production systems. The MVP accepts redacted YAML fixtures and emits local Markdown reports only.
