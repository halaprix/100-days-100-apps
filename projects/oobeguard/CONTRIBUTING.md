# Contributing

OOBEGuard is in early incubation.

## Development rules

- Keep examples fictional and public-safe.
- Add a synthetic fixture for every new rule.
- Add a public documentation link for every blocker/warning.
- Avoid broad endpoint-management scope creep.
- Use conventional commits.

## Local validation

Before opening a PR, run the available tests and repository hygiene checks. The initial scaffold only validates required files; implementation checks will be added with the first CLI slice.
