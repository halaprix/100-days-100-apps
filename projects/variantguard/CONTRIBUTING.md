# Contributing

## Development rules

1. Create and claim a Beads issue before changing product code.
2. Keep the tool local, read-only, and credential-free.
3. Add a fixture or test for behavior changes.
4. Run the relevant tests and `python3 scripts/verify_scaffold.py`.
5. Use a Conventional Commit and reference the Beads issue.

## Security reports

Do not open public issues for vulnerabilities or potential data exposure. See
[SECURITY.md](SECURITY.md).
