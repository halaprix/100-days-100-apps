# Contributing

SheetSentry is early-stage. Keep contributions small, testable, and public-safe.

## Development rules

- Open or claim a Beads issue before changing code.
- Use Conventional Commits.
- Add or update fixtures for detector behavior.
- Avoid live-network requirements in CI unless explicitly marked optional.

## Pull request checklist

- [ ] The change is linked to a Beads issue.
- [ ] Tests or fixture checks cover the behavior.
- [ ] No secrets, cookies, OAuth details, or private sheet URLs are committed.
- [ ] Documentation is updated when behavior changes.
