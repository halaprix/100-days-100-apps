# Security Policy

## Supported versions

WeatherFork is pre-release. Only the current `main` branch is supported during incubation.

## Reporting a vulnerability

Open a private report through the repository's security advisory flow if available, or contact the maintainer through the public repository profile.

## Public-safety constraints

Do not include the following in issues, examples, pull requests, screenshots, or fixtures:

- Real station identifiers or passkeys.
- Exact home coordinates or addresses.
- Private hostnames, internal network details, or non-public URLs.
- Raw personal weather logs tied to a household.
- Credentials or platform secrets.

Use synthetic fixtures that preserve field shape without identifying a real station or home.
