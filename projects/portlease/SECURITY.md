# Security Policy

## Supported versions

PortLease is pre-release. Only the latest main branch is supported.

## Reporting a vulnerability

Open a GitHub security advisory or contact the maintainer privately through GitHub.

## Data handling

PortLease should not require secrets, router credentials, cloud accounts, or telemetry in v0. Do not paste real router dumps, private IP screenshots, MAC addresses, hostnames, or home-network details into public issues.

Sample scans must be synthetic or based only on public, non-sensitive information.

PortLease output is diagnostic support only. It does not prove compromise, replace router documentation, or replace a professional security assessment.
