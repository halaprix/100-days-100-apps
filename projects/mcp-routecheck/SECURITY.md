# Security policy

## Scope

McpRouteCheck is intended to process local configuration files that may contain
sensitive fields. The MVP must not transmit inputs, invoke authentication, or
include credential values in output.

## Reporting a vulnerability

Do not file public issues containing credentials or configuration data. Report
security concerns privately to the repository owner with a minimal synthetic
reproduction and a description of impact.

## Supported versions

Only the latest development version is supported before the first stable release.
