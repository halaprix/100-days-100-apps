# Agent Instructions — NIS2 EvidencePack

This repo is a public software MVP spawned from the 100 Days, 100 Apps lab.

## Rules

- Keep all committed artifacts public-safe: no secrets, credentials, private hostnames, private paths, customer data, or screenshots containing personal information.
- This is a software app, not legal advice. Avoid claims that the tool certifies compliance.
- Use Beads (`bd`) for task tracking. Do not use markdown task lists as the tracker.
- Prefer local-first design. The MVP must not require cloud admin credentials.
- Use conventional commits and reference beads in commit bodies.
- If GitHub push fails with permissions, record the blocker and stop retrying identical pushes.

## Product boundary

NIS2 EvidencePack is an offline evidence-binder generator for small EU IT teams. It is not a GRC SaaS, legal service, or compliance certification platform.
