# Contributing

Thanks for considering a contribution.

## Workflow

1. Open or claim a Beads issue with `bd`.
2. Make one logical change per commit.
3. Use conventional commit messages.
4. Keep changes public-safe: no secrets, customer data, private paths, private hostnames, or screenshots with personal information.
5. Add or update tests/checks when code lands.

## Product constraints

- Do not add legal-advice language.
- Do not require cloud admin credentials for the MVP.
- Prefer deterministic local processing before optional AI features.
