# Security Policy

## Reporting a vulnerability

Please open a private security advisory on GitHub when available. If that is not available, contact the repository owner through the public profile.

## Data handling principles

- Do not commit real customer evidence packs.
- Do not commit secrets, API keys, tokens, private hostnames, or private IPs.
- Test fixtures must be synthetic and clearly marked as examples.
- The MVP should run locally and avoid storing cloud admin credentials.
