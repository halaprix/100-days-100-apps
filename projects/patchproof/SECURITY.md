# Security

## Supported versions

PatchProof is scaffold-only. No production version is supported yet.

## Reporting

Open a GitHub issue in the parent 100-days repo for public, non-sensitive reports. Do not include secrets, real hostnames, IP addresses, user names, ticket IDs, asset tags, screenshots, vulnerability data from private systems, or internal environment details.

## Data handling boundary

The MVP must stay local-only and static-export based. It must not request live platform credentials, control endpoints, deploy patches, trigger scanner actions, or upload evidence to a cloud service.
