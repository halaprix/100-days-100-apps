# Contributing

PatchProof is early-stage. Keep contributions small, public-safe, and tied to the static-export MVP.

## Workflow

1. Create or claim a Beads issue.
2. Make one logical change.
3. Run the scaffold verifier or future parser/report tests.
4. Commit with Conventional Commits and reference the Beads issue.

## Public-safety requirements

Do not commit real hostnames, IP addresses, user names, email addresses, ticket IDs, asset tags, vulnerability data from private systems, screenshots, tokens, credentials, or private infrastructure details.
