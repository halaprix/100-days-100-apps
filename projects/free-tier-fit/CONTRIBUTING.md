# Contributing

FreeTierFit is early-stage. Keep contributions small, testable, and public-safe.

## Development rules

- Open or claim a Beads issue before changing code.
- Use Conventional Commits.
- Add or update Compose/catalog fixtures for scoring behavior.
- Avoid live cloud-provider requirements in CI.
- Do not commit secrets, host inventories, private Compose files, or private URLs.

## Pull request checklist

- [ ] The change is linked to a Beads issue.
- [ ] Tests or fixture checks cover the behavior.
- [ ] No credentials, provider tokens, private hostnames, or private infrastructure details are committed.
- [ ] Documentation is updated when behavior changes.
