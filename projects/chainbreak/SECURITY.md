# Security Policy

## Scope

ChainBreak is intended to process selected local dependency fixtures. The MVP must not transmit files, use credentials, open network connections, probe devices, or modify infrastructure.

## Reporting

Do not open a public issue with a real topology, hostname, IP address, VPN configuration, device identifier, credential, or incident log. Report issues privately to the repository maintainer with a minimized synthetic reproduction where possible.

## Supported versions

Only the current development branch is supported before the first stable release.
