# Security policy

## Supported versions

Until a runnable release exists, only the default branch is supported.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Contact the repository owner privately with a minimal reproduction and avoid sending credentials, customer crawls, cookies, or production URLs.

## Data-handling boundary

RedirectLedger is designed for local files. It must not collect or transmit site content, authentication data, headers, cookies, or redirect-management credentials. Any future network feature requires an explicit security review and opt-in.
