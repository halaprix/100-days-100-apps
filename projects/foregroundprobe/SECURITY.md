# Security Policy

## Scope

ForegroundProbe is intended to process locally selected project metadata. The MVP must not transmit files, use credentials, control devices, or modify Android manifests.

## Reporting

Do not open a public issue with a real app manifest, device identifier, Logcat extract, credential, or proprietary project metadata. Report the issue privately to the repository maintainer with a minimized synthetic reproduction where possible.

## Supported versions

Only the current development branch is supported before the first stable release.
