# Security

## Supported versions

DrivePing is scaffold-only. No production version is supported yet.

## Reporting

Open a GitHub issue in the parent 100-days repo for public, non-sensitive reports. Do not include secrets, route traces, device identifiers, precise locations, SSIDs, IP addresses, or packet captures.

## Data handling boundary

The MVP must stay local-only and must not request background location, VPN, packet-capture, contacts, SMS, microphone, camera, or accessibility permissions.
