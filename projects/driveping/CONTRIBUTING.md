# Contributing

DrivePing is early-stage. Keep contributions small, public-safe, and tied to the MVP.

## Workflow

1. Create or claim a Beads issue.
2. Make one logical change.
3. Run the scaffold verifier or future Android tests.
4. Commit with Conventional Commits and reference the Beads issue.

## Public-safety requirements

Do not commit real route traces, precise locations, SSIDs, device identifiers, IP addresses, hostnames, app traffic captures, tokens, or private infrastructure details.
