# Contributing

QuadletState is in incubator status. Keep contributions small, public-safe, and tied to the MVP.

## Workflow

1. Create or claim a Beads issue with `bd`.
2. Make one logical change.
3. Run `python3 scripts/verify_scaffold.py` and any project tests that exist.
4. Commit with a Conventional Commit message.

## Public-safety constraints

Do not commit real `.env` files, tokens, hostnames, IP addresses, private paths, service inventories, or screenshots from a real server. Use synthetic examples only.
