# Security Policy

## Supported versions

TzDrift is pre-release. Only the latest main branch is supported.

## Reporting a vulnerability

Open a GitHub security advisory or contact the maintainer privately through GitHub.

## Data handling

TzDrift should not require secrets, credentials, SSH keys, cloud accounts, or telemetry in v0. Do not paste real host inventories, private IPs, hostnames, customer names, tenant names, or infrastructure dumps into public issues.

Sample reports must be synthetic or based only on public, non-sensitive information.

TzDrift output is operational decision support only. It does not predict legislation, replace vendor patch guidance, or provide legal/compliance advice.
