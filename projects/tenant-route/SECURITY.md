# Security Policy

## Supported versions

TenantRoute is pre-release. Only the latest main branch is supported.

## Reporting a vulnerability

Open a GitHub security advisory or contact the maintainer privately through GitHub.

## Data handling

TenantRoute should not require secrets or credentialed Microsoft APIs in v0. Do not paste real tenant IDs, private domains, support tickets, billing exports, or customer data into public issues.

Sample scenarios must be synthetic or based only on public, non-sensitive information.

TenantRoute output is decision support only. It is not legal, tax, compliance, Microsoft support, or migration advice.
