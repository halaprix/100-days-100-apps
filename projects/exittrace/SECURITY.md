# Security Policy

## Supported versions

ExitTrace is pre-release. Security fixes target the latest `main` branch until the first stable release.

## Reporting a vulnerability

Open a private GitHub security advisory or contact the maintainer through GitHub.

Do not include real survivor-service URLs, private audit reports, secrets, cookies, or identifying screenshots in public issues.

## Safety limitations

ExitTrace is operational decision support for web teams. It does not make monitored browsing safe, erase browser history, detect spyware/stalkerware, or replace expert survivor-safety guidance.
