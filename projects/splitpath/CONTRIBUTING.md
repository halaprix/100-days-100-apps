# Contributing

Thanks for considering a contribution.

## Development workflow

1. Pick or create a Beads issue with `bd`.
2. Keep changes small and public-safe.
3. Add fixture coverage for every diagnostic rule.
4. Run the local checks before committing.
5. Use Conventional Commits.

## Public-safety policy

Do not include real private hostnames, private IP maps, API tokens, cookies, tunnel credentials, router exports, Cloudflare account data, Tailscale/NetBird tokens, or screenshots with personal data. Use synthetic examples such as `service.example.com` and documentation ranges.
