# Contributing

Contributions are welcome once the MVP lands.

## Development principles

- Keep checks local-first and read-only by default.
- Use synthetic campaign fixtures, not real business submissions.
- Redact phone numbers, addresses, emails, and customer names in all shareable output.
- Add tests for every new rule.

## Commits

Use Conventional Commits:

```text
feat: add fixture campaign check
fix: redact phone numbers in markdown output
```

Do not add co-author trailers for LLM agents.
